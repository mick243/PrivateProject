# 시각 디자인 기준

> 2026-09-29 작성. 화면의 **생김새**(색 · 글꼴 · 간격 · 모서리 · 부품 모양)의 정본입니다.
> 무엇을 어떤 말로 쓰고 한 화면에 무엇을 둘지는 [DESIGN-GUIDE.md](DESIGN-GUIDE.md)(디자인 · UX 라이팅 지침)가
> 정본이고, 이 문서는 그 아래에서 "어떻게 보이게 하나" 만 다룹니다. 값 자체는 `app/globals.css` 첫머리의 토큰이 정본입니다.

## 0. 왜 다시 잡았나

2026-09-29 이전 판은 틀린 곳은 없었지만 **"AI 가 만든 대시보드"** 로 읽혔습니다. 짚이는 까닭은 이랬습니다.

| 티가 나던 것 | 어디 | 지금 |
|---|---|---|
| 남색 바탕 + 파랑 · 민트 두 강조색 | 전 화면 | 회색이 끌고 강조색은 파랑 하나 |
| 색이 다른 그라데이션 카드 넷 · 얇은 선 아이콘 | 홈 바로 가기 | 같은 회색 판 넷, 다른 것은 아이콘뿐 |
| 남색 · 틸 · 인디고 그라데이션 배너 | 홈 소식 배너 | 짙은 단색 넷, 940px 기둥 안의 둥근 판 |
| 자간 넓힌 영문 대문자 로고 `ARCADE` | 상단 네비 | 한글 이름표 `오락실 파인더` + 오락실 버튼 점 |
| 알약 배경으로 칠한 현재 메뉴 · 탭 | 네비 · 게임 탭 | 굵은 글자 + 밑줄 한 줄 |
| 고른 칩 · 페이지 · 정렬을 전부 강조색으로 채움 | 필터 줄 | 먹색으로 뒤집기 — 강조색은 주 버튼 몫 |
| 줄마다 둥근 상자 · 호버 때 강조색 테두리 | 오락실 목록 · 글 목록 | 가는 선으로 나눈 줄, 호버는 바탕 한 겹 |
| 이모지 아이콘 `💬` `📍` | 챗봇 단추 · 설치 안내 | 선 아이콘 |
| 선언만 되고 파일이 없던 `Pretendard` | 전 화면 | 실제로 불러옴 (Windows 는 그동안 맑은 고딕이었음) |
| 2색 그라데이션 점수 막대 | 추천 순위 | 단색 막대 |

**참고한 것** — 당근 [SEED 디자인 시스템](https://github.com/daangn/seed-design)의 규칙(회색이 주도하는 판판한 화면 ·
4px 간격 · 모서리 세 가지 · 한 화면에 채운 버튼 하나)과 그 요약본 [daangn-seed-ai](https://github.com/byunghun-ben/daangn-seed-ai)의
"AI 티 나는 패턴 13가지", 회색 단계는 토스 TDS 의 따뜻한 회색 계열. 색 값을 그대로 가져오지 않고 **규칙**을 가져왔습니다.
강조색은 처음에 주황(`#e8490f`)으로 잡았다가 같은 날 사용자 요청으로 **파랑**(`#2272eb`)으로 바꿨습니다 —
흰 글자를 얹었을 때 대비 4.5:1 에 가까운 값입니다.

## 1. 색

역할 이름으로만 씁니다. `#fff` 같은 값을 규칙 안에 새로 적지 않습니다 (예외는 §1-3).

| 토큰 | 역할 | 라이트 | 다크 |
|---|---|---|---|
| `--bg` · `--panel` | 페이지 · 판 | `#ffffff` · `#ffffff` | `#16171b` · `#1b1d22` |
| `--panel-2` | 회색 채움(보조 버튼 · 입력 없는 칸 · 섹션 띠) | `#f3f4f5` | `#2b2e35` |
| `--card-cap` | 홈 카드 · 공지 줄 · 실시간 줄의 바탕 | `#f7f8f9` | `#22252b` |
| `--line` · `--line-strong` | 나누는 선 · 입력 칸 테두리 | `#eeeff1` · `#dcdee3` | `#2b2e35` · `#393d46` |
| `--text` · `--muted` · `--subtle` | 글자 1 · 2 · 3순위 | `#1a1c20` · `#555d6d` · `#868b94` | `#f3f4f5` · `#b0b3ba` · `#868b94` |
| `--accent` | 브랜드(주 버튼 · 지도 점 · 포커스) | `#2272eb` | `#3b82f6` |
| `--accent-2` | 좋음 · 있음 · 켜짐 | `#079171` | `#22b27f` |
| `--danger` · `--warn` · `--info` | 오류 · 주의 · 글 속 링크 | `#e5302a` · `#9b7821` · `#217cf9` | `#ff6e60` · `#ca901c` · `#41a2f9` |
| `--text-accent` 등 `--text-*` | 옅은 틴트 **위에 얹는 글자** | 진하게 | 밝게 |

### 1-1. 강조색을 쓰는 곳 (여기뿐)

- `.btn-primary` — 한 화면에 하나 (DESIGN-GUIDE §1-2)
- 지도의 오락실 점(`.mk-dot`) · 순위 1위 뱃지 · 고른 목록 줄의 왼쪽 막대
- 키보드 포커스 링(`:focus-visible`) · 네비 이름표 앞의 점
- 관리자 표시(`.admin-tag`) · 공지 말머리(`.cat-notice`)

그 밖의 "고른 것"(칩 · 서열표 곡 칩 · 페이지 번호 · 정렬 · 네비의 현재 화면)은 **먹색으로 뒤집습니다**(`--text` 바탕 + `--bg` 글자).

### 1-2. 틴트

옅게 깐 색은 토큰이 아니라 `color-mix(in srgb, var(--accent) 12%, transparent)` 로 씁니다. 두 테마에서 따로 적을 필요가 없고,
강조색을 바꾸면 틴트도 따라옵니다. 예전의 `rgba(53, 110, 230, 0.16)` 처럼 옛 강조색 값을 박은 틴트는 모두 이 꼴로 바꿨습니다.

### 1-3. 테마와 무관하게 고정한 색

- **지도 위의 것** — 고른 핀 `#1a1c20`(먹색 알약), 내 위치 `#f0561d`(주황 — 오락실 점이 파랑이라 겹치지 않게). 네이버 지도 타일은 다크 테마에서도 밝아서,
  테마를 따라 흰색으로 뒤집히면 지도 위에서 묻힙니다.
- **서열표 등급 막대** — 데이터 색입니다. 최상 `#fa342c` → 최하 회색, 개인차 보라 `#9061f9`, 특수패턴 분홍 `#e0457b`.
  등급 일곱과 겹치는 계열이 없게 골랐습니다.
- **소식 배너** — 늘 어두운 판이라 글자 · 이름표는 흰색 고정.
- **소셜 로그인 단추** — 각 사 브랜드 가이드 (`OAuthButtons.tsx`).

## 2. 글꼴과 글자 크기

- **Pretendard Variable** 을 `app/fonts/pretendard/` 에 두고 `app/layout.tsx` 가 불러옵니다(OFL-1.1, 라이선스 파일 동봉).
  글자 범위별 조각(92개)이라 화면에 나온 글자가 든 조각만 받습니다. CSP 가 `font-src 'self'` 라 CDN 을 쓰지 않습니다.
- 한글은 **어절 단위 줄바꿈**(`word-break: keep-all`). 띄어쓰기 없는 일본어 제목이 들어오는 자리는 `overflow-wrap: anywhere`.
- 크기는 여덟 단계만 씁니다.

| 토큰 | px | 쓰는 곳 |
|---|---|---|
| `--t2` | 12 | 이름표 · 날짜 · 조회수 |
| `--t3` | 13 | 주소 · 도움말 · 칩 · 작은 버튼 |
| `--t4` | 14 | 본문 기본 |
| `--t5` | 16 | 목록 제목 · 섹션 제목 · 글 본문 · 탭 |
| `--t6` | 18 | 폼 제목 |
| `--t7` | 20 | 오락실 상세 이름 · 홈 섹션 제목 |
| `--t8` | 22 | 화면 제목(h1) |
| `--t9` | 26 | (예비) |

제목은 굵게(700) · 자간 −0.02em. 10px 대 글자는 지도 마커 안의 숫자처럼 자리가 정해진 곳에만 남았습니다.

## 3. 모양

- **간격** — 4의 배수. 판 안쪽 16px, 섹션 사이 24px 이상.
- **모서리** — `--r-xs` 4(이름표) · `--r-sm` 8(버튼 · 입력 칸 · 작은 판) · `--r-md` 12(카드 · 배너 · 떠 있는 창) · `--r-full`(칩 · 원형 단추).
  옛 이름 `--radius` 는 `--r-sm` 과 같은 값으로 남겨 뒀습니다.
- **그림자** — 떠 있는 것(지도 위 판 · 펼친 메뉴 · 챗봇 창 · 떠 있는 단추 · 나눈 단추의 고른 칸)에만. 버튼 · 카드 · 목록은 납작합니다.
- **호버** — 테두리를 칠하지 않고 바탕을 한 겹 어둡게(`--overlay`, `--panel-2`). 떠오르는 효과(`translateY`)는 쓰지 않습니다.

| 부품 | 모양 |
|---|---|
| `.btn` | 높이 36 · 회색 채움 · 테두리 없음 · 600. `.btn-sm` 28. 폼 화면(`.login-card`)에서는 48 |
| `.btn-primary` | 강조색 채움 + 흰 글자 |

| 입력 칸 | 높이 40 · 판 색 바탕 · `--line-strong` 테두리 · 포커스 때 테두리가 글자색 |
| `.chip` | 알약 · 테두리 · 고르면 먹색 |
| `.badge` · `.cat` · `.wait` · `.factor` · `.rank` | 네모 이름표(모서리 4) · 12px. 읽기만 하는 표시는 알약이 아니다 |
| `.seg` | 회색 홈 안에서 고른 칸만 떠오름 (`--raised`) |
| `.game-tab` · `.topnav-link` | 밑줄 탭 |
| 목록 줄 | 가는 선으로 나눔. 고른 줄은 왼쪽 강조색 막대 + 옅은 틴트 |

| `.hint` | 회색 판 + 회색 글자. 색을 입히면 경고로 읽힌다 |
| 지도 점 | 강조색 점 · 흰 테두리. 고른 곳은 먹색 알약 |
| 챗봇 단추 | 먹색 원 + 말풍선 선 아이콘 |

## 5. 점검표 — 화면을 고친 PR 마다

- [ ] 규칙 안에 새 색 값(`#…` · `rgba(…)`)을 적지 않았다. 적었다면 §1-3 의 고정색이다.
- [ ] 그라데이션을 새로 쓰지 않았다 (가로 스크롤 줄 끝의 페이드 · 사진 위 어두운 막은 예외).
- [ ] 강조색을 §1-1 밖에 쓰지 않았다. "고른 것" 은 먹색.
- [ ] 글자 크기는 `--t*` 토큰, 모서리는 `--r-*` 토큰.
- [ ] 버튼 · 카드에 그림자나 떠오르는 효과가 없다.
- [ ] 이모지를 아이콘으로 쓰지 않았다.
- [ ] 라이트 · 다크 두 테마와 375px 폭에서 봤다.

## 6. 이 판을 만들 때 남긴 것

- **구조는 건드리지 않았습니다.** 화면 구성 · 문구는 DESIGN-GUIDE 쪽 작업(다른 워크트리, 미커밋)이 바꾸고 있어서,
  이 작업은 `globals.css` 중심으로 하고 TSX 는 생김새에 꼭 필요한 곳만 고쳤습니다 — 홈 카드 마크업 · 배너 배경 · 네비 이름표 ·
  챗봇 · 설치 안내 아이콘 · 검색 단추 둘의 무게(`btn-primary` → `btn`, 한 화면 주 버튼 하나).
- 네비의 `/finder` 메뉴 이름을 `오락실 파인더` → `오락실 찾기` 로 바꿨습니다. 이름표가 `오락실 파인더` 가 되면서 같은 말이 나란히 섰기 때문입니다.
- 관리자 화면 · 이모티콘 · 편집기 도구 막대 · 지도 성능 패널은 토큰이 바뀐 만큼만 따라왔고 따로 다듬지 않았습니다.
